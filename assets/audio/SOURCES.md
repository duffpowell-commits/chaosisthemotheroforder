# Sound sources

Every clip here is a real recording, cut and levelled by `tools/real_audio.py` (standards item 6, Nov 26).
All are **CC0** (public domain dedication) from OpenGameArt.org, so nothing needs a credit in the game;
this list is kept anyway. A rule test checks every `.ogg` in this folder has a row.
