# Open the project in Godot on Android

1. On GitHub, open this repo, switch to branch `ccr-61f68548-sahgbb`
   (until PR #1 is merged; after that, `main`).
2. Tap **Code → Download ZIP** and unzip it (Files app → tap the zip → Extract).
3. Open the **Godot** app → **Import** → browse to the unzipped folder →
   pick `project.godot` → **Import & Edit**.
4. The first import takes a few minutes (it converts the textures).
5. Tap **Run** (the play button, top right).
6. Drag the slider at the bottom to take the district from the regime.

The project uses Godot 4.5 and the Mobile renderer.
